## Featured Project

### [Home Value Prediction App](https://github.com/pratama-dev/homevalue-streamlit)

An end-to-end **machine learning application for house price prediction** based on key property features.

Built with **Python and Streamlit**, the application uses a trained regression model to provide real-time price predictions through an interactive web interface.

**Technologies:** Python, Pandas, Scikit-learn, Streamlit, Machine Learning

**Live Demo:** [Home Value Prediction App](https://homevalue-predictor.streamlit.app/)
